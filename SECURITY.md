# Security Policy

**English** · [Русский](SECURITY.ru.md)

## Reporting a vulnerability

Do not report security vulnerabilities through public issues, discussions, or
pull requests.

Instead:

1. Use **Report a vulnerability** in the affected repository's **Security** tab, or
2. Email [security@pteris.in](mailto:security@pteris.in).

Please include a description, impact, reproduction steps, and the affected
repository or commit.

## What to expect

| Stage | Target |
| --- | --- |
| Acknowledgement | within 3 business days |
| Initial assessment | within 7 business days |
| Fix or mitigation for confirmed high/critical issues | within 90 days |

## Supported versions

Unless stated otherwise, only the latest release and the `main` branch receive
security updates.
